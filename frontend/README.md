# NAVYA — Microgrid Operations Dashboard

React 19 operator console for the NAVYA autonomous microgrid management platform.

## Features
- **Control Center:** Live power flow digital twin (Solar, Wind, Battery, Diesel)
- **Forecast:** Generation and demand projections across multiple horizons
- **Scenarios:** Stress-testing what-if simulator with comparison engine
- **Community:** Public signal relay & ambient status kiosk (`/community-display`)
- **Event History & Settings:** System telemetry logs and dispatch parameters

## Development

```bash
# Install dependencies
npm install

# Start development server (Port 3000)
npm run dev

# Build for production
npm run build
```
